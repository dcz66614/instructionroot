# Import-Graph Golden Fixtures (T005)

Synthetic workspaces for the import graph + escape detection,
generated by `build_imports_fixtures.py` (re-run it to rebuild; do
not hand-edit the case trees). All content is synthetic
placeholder text; zero real users, zero real repos.

## Layout

```text
01_s0/fixtures/imports/
├── build_imports_fixtures.py  # generator (deterministic, idempotent)
├── manifest.json              # case list
└── <case-id>/
    ├── case.json              # input (frozen format + T003 extensions)
    ├── <case-id>.expected.json
    ├── home/                  # synthetic HOME
    ├── repo/                  # synthetic repo (no .git: git state is T004)
    ├── outside/               # synthetic outside-repo dir, if any
    └── extra/                 # synthetic custom-instructions dir, if any
```

## `<case-id>.expected.json` — imports-stage scope

```json
{
  "expected_verdict": "BLOCK",
  "expected_edge_count": 3,
  "expected_edges": [
    {"from_relative_path": "repo/CLAUDE.md", "syntax": "@../outside/secret.md",
     "depth": 1, "relative_target": "outside/secret.md",
     "relative_resolved_target": "outside/secret.md",
     "allowed": false, "reason": "IMPORT_ESCAPE"}
  ]
}
```

- `relative_target` is the edge's **canonical** (lexical) target,
  relative to the case directory — `null` when the reference cannot
  be resolved (MISSING / UNRESOLVABLE). An absolute target outside
  the case tree (e.g. `/etc/...`) is written as the absolute path.
- `relative_resolved_target` is the **resolved** target (after
  symlink resolution); it differs from `relative_target` exactly
  for symlink escapes. `null` when the target cannot be resolved.
- `depth` counts hops from a discovered source (a direct import is 1).
- `reason` is one of `WITHIN_REPO`, `WITHIN_HOME`,
  `WITHIN_CUSTOM_DIR`, `IMPORT_ESCAPE`, `MISSING`, `DEPTH_EXCEEDED`,
  `UNRESOLVABLE` (see `02_src/instructionroot/imports.py`).

## Comparison rules (`scripts/run_golden.py --stage imports`)

- **edge_parity**: the multiset of
  `(from, syntax, depth, canonical target, resolved target, allowed, reason)`
  must match exactly, for every case.
- **escape_detection**: every expected edge with `allowed=false`
  must be produced with `allowed=false` (i.e. no escape / missing /
  depth violation is missed). Reported as a percentage over all
  expected blocked edges.
- **verdict**: derived by `receipt.derive_verdict` over receipt
  sources built with **synthetic trust** — in-repo files are treated
  as `GIT_TRACKED`, home files as `USER_SCOPE` (via the real T004
  classifier with a synthetic tracked GitState). Real Git state is
  T004/T007's job; this stage pins the edge→verdict link only.
  A verdict mismatch fails the case, like an edge mismatch.

Output (last lines, machine-readable):

```text
cases=15 passed=15 failed=0
golden_edge_parity=100.0%
golden_escape_detection=100.0%
```

Exit code 0 only when both metrics are 100% and every case passes.
No network, no wall-clock in any comparison; only paths, depths,
reasons and verdicts are compared — never file contents.
